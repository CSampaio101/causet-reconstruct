# Reconstructing a causal set from nonlinear spectral data

Code for the MSc thesis

> Cristiano Sampaio, *Hearing the Shape of Spacetime Using Nonlinearities in Causal Set Theory*,
> University of Waterloo, 2026.

Section, table and figure numbers below refer to the thesis. Appendix B of the thesis describes this program.

## What the code does

One cannot, in general, hear the shape of a drum: the spectrum of a wave operator does not determine the geometry. The thesis shows that a causal set *is* determined, up to a relabelling of its elements, once the spectrum is supplemented by suitable nonlinear data, namely the components of a local cubic or quartic interaction vertex in the eigenbasis of the wave operator.

`causet_reconstruct.py` carries out this reconstruction numerically. It has two stages, which are kept separate.

1. **Forward stage (Section 6.1).** Starting from a causal set, it builds the Benincasa-Dowker matrix $B$ and the Hermitian matrix $\tilde B = \tfrac12(B+B^T) + \tfrac{i}{2}(B-B^T)$, diagonalizes $\tilde B$, and computes the components of the requested representations of the cubic and quartic vertices in an eigenbasis of $\tilde B$.
2. **Inverse stage (Section 6.2).** It receives only the eigenvalues and the vertex components, and nothing else. From these it
   - recovers the unitary $U$ between the position basis and the eigenbasis, up to a permutation and a phase per column, by contracting a vertex with a random probe (Chapter 4);
   - restricts the column phases using the vertex data (Sections 5.6 to 5.9);
   - reconstructs $\tilde B$ in the position basis and uses the fact that only certain coefficients can occur in $B$ ("BD legality", Sections 5.4 and 5.10) to fix the remaining phases, searching over every assignment that is left;
   - decodes $B$, reads off the links and takes the transitive closure.

Once the inverse stage has finished, the recovered causal set is compared with the input, and the consistency checks of Section 6.3 are evaluated. The causal set is recovered up to a relabelling of its elements. If the supplied vertex data are not sufficient (for example the quartic $4\to0$ representation alone), the program returns every causal set that is consistent with the data.

## Scope and limitations

- **The program needs a causal set to start from.** It does not read spectral data from outside: the input data of the reconstruction are generated by the forward stage from a causal set that is given by its relations (`--links`), by its Benincasa-Dowker matrix (`--bd-file`), or by placing points at random in a box of flat Minkowski spacetime (`--sprinkle`). Sprinklings into curved spacetimes are not included. This could be remedied by supplying the program with a generator of causal sets by Poisson sprinkling into a given spacetime manifold; the output of any such generator can already be passed in through `--links` or `--bd-file`.
- **Dimensions.** The Benincasa-Dowker coefficients of 3+1 and of 1+1 dimensions are implemented (`--scheme`).
- **Size.** The vertex components are stored as full tensors, $N^3$ numbers for a cubic and $N^4$ for a quartic vertex, so the memory grows quickly with the number of elements $N$ (about 100 MB for one quartic representation at $N=50$, and 1.6 GB at $N=100$). The examples of the thesis have $N \le 23$.
- **Exact data.** The input data are exact up to rounding. The effect of noise in the data on the reconstruction has not been studied.

## Quick start

```bash
# sprinkle 20 points into Minkowski spacetime and reconstruct the causal set
python causet_reconstruct.py --sprinkle 20

# the same in 1+1 dimensions
python causet_reconstruct.py --sprinkle 20 --scheme 1+1

# a causal set given by its relations, with a figure of the input and the result
python causet_reconstruct.py --links "a<b<e<f,a<c<e,a<d" --figure result.png
```

## Conventions

**Causal sets.** A causal set is passed as a list of relations separated by commas, in which `x<y` means that x precedes y. Chains such as `a<b<e` are allowed, and the transitive closure is taken. The elements are ordered alphabetically.

**Representations.** A representation of a vertex is passed as two integers `p,q`, the number of ket legs followed by the number of bra legs. In the notation of the thesis this is the $q \to p$ representation. The program prints a representation in the same order, so that the line `quartic 0->4` in its output refers to the quartic $4\to0$ representation. A vertex is omitted with `none`.

| Representation | Option |
|---|---|
| cubic $2\to1$ | `--cubic 1,2` |
| cubic $3\to0$ | `--cubic 0,3` |
| quartic $3\to1$ | `--quartic 1,3` |
| quartic $4\to0$ | `--quartic 0,4` |
| quartic $2\to2$ | `--quartic 2,2` |

**Random choices.** Two random choices are made, both controlled by `--seed` (default 0). The first is the eigenbasis of $\tilde B$ in which the vertex components are given: the eigenvectors are permuted, multiplied by random phases, and rotated by a random unitary within each degenerate eigenspace, so that the inverse stage cannot make use of any ordering. The second is the probe, whose components are complex Gaussian. With `--sprinkle`, the seed also selects the sprinkling.

## Options

The first five select the causal set, and only one of them can be given.

| Option | Meaning |
|---|---|
| `--links R` | causal set given by the relations `R` |
| `--sprinkle N` | `N` points placed at random in a unit box of Minkowski spacetime |
| `--blindspot` | the six-element causal set of Section 5.5.3 |
| `--bd-file F` | causal set read from a Benincasa-Dowker matrix stored in the file `F` (`.npy` or text) |
| `--example20` | a stored 20-element causal set (used if no causal set is given) |
| `--scheme` | dimension, `3+1` (default) or `1+1` |
| `--cubic p,q` | representation of the cubic vertex, or `none` (default `1,2`) |
| `--quartic p,q` | representation of the quartic vertex, or `none` (default `1,3`) |
| `--recover-from` | vertex that is contracted to recover $U$, `cubic` or `quartic` |
| `--g`, `--lam` | couplings $g$ and $\lambda$ (default 1) |
| `--random-volumes` | weights $\nu_m$ drawn at random between 0.5 and 1.5 in place of $\nu_m=1$ |
| `--seed s` | seed of the random choices (default 0) |
| `--enumerate n` | largest number of consistent phase assignments returned for each decoder (default 1); the search is exhaustive unless this number is reached |
| `--figure F` | draw the input and the recovered causal sets and save the figure as `F` |
| `--match-labels` | in the figure, name each recovered element after the input element it corresponds to |
| `--highlight` | with `--match-labels`, draw in colour the links that differ between the panels |
| `--only-blind-spots` | in the figure, show the input and only the recovered causal sets that are not isomorphic to it or to its time reverse |
| `--labels` | name the elements by `letters` (default) or `numbers` |
| `--draw-only` | print the Benincasa-Dowker matrix and draw the causal set, without reconstructing it |

`--match-labels` uses the unitary $U$ of the forward stage, which the inverse stage does not see. It affects only the names shown in the figure and in the printed output, and not the reconstruction.

## Output

The program prints one line for each step of the reconstruction, followed by the checks and the comparison with the input.

| Printed | Quantity |
|---|---|
| `Spectrum` | smallest and largest eigenvalue of $\tilde B$, the sum of the eigenvalues and the sum of their squares (Section 2.3) |
| `Probe attempt k` | number of probes drawn until one was accepted |
| `min relative gap` | smallest separation between two weights of the probe contraction, relative to the largest |
| `Eigenpair ratio vs self-contraction` | largest relative difference between the eigenpair ratio and the self-contraction over the columns |
| `Residual` | residual set of the column phases after the vertex data have been used |
| `BD legality search` | number of consistent phase assignments found with $D_+$ and with $D_-$ |
| `off-diagonal fraction` | part of the vertex tensor outside the diagonal in the recovered basis, relative to its norm |
| `s3/s4 ratio` | mean of the ratio of the diagonal entries of the two vertices, and its largest relative deviation from the mean |
| `Post-hoc` | comparison of the recovered causal set with the input |
| `Relabeling` | one isomorphism from the input labels to the recovered labels |
| `pairwise distinct` | number of causal sets returned, up to relabelling and time reversal |

## Reproducing the results of the thesis

All commands use the default seed.

**Figure 2.1** (the command also prints the matrix $B$):

```bash
python causet_reconstruct.py --links "a<b<e<f,a<c<e,a<d" --draw-only --figure bd_example.png
```

**Figure 5.1**, the blind spot of Section 5.5.3:

```bash
python causet_reconstruct.py --blindspot --cubic none --quartic 0,4 --enumerate 20 --only-blind-spots --figure blind_spot.pdf
```

**Chapter 7.** The 23-element causal set is

```bash
LINKS="a<b,a<c,a<p,b<d,b<e,c<e,c<f,d<g,e<h,f<i,f<j,g<k,h<k,i<l,j<l,k<m,l<n,m<o,n<o,p<q,p<r,q<s,s<t,f<v<l,f<w<l,i<u,j<u,v<u,w<u"
```

Figure 7.1, the reconstruction from the quartic $4\to0$ representation alone, which returns two causal sets:

```bash
python causet_reconstruct.py --links "$LINKS" --cubic none --quartic 0,4 --enumerate 20 --match-labels --highlight --figure example23_blindspot.png
```

Figure 7.2, with the cubic $3\to0$ representation added, which returns the input causal set. This command also prints the relabelling of Eq. (7.2):

```bash
python causet_reconstruct.py --links "$LINKS" --cubic 0,3 --quartic 0,4 --figure example23_with_cubic.png
```

Table 7.1. Each row is obtained from

```bash
python causet_reconstruct.py --links "$LINKS" --cubic C --quartic Q --enumerate 20
```

with `C` and `Q` set, row by row, to `1,2` and `1,3`; `1,2` and `none`; `0,3` and `0,4`; `none` and `1,3`; `0,3` and `none`; `0,3` and `2,2`; `none` and `0,4`; `none` and `2,2`.

Section 7.5. The repetitions are obtained by adding `--seed 1` to `--seed 5` to the two commands for Figures 7.1 and 7.2, and the reconstruction with random weights by adding `--random-volumes` to the second.

**Number of phase assignments.** The number 3222 of phase assignments that satisfy the Lemma of Section 5.4 on all pairs is not printed by `causet_reconstruct.py`. It is obtained with

```bash
python count_assignments.py --links "$LINKS"
```

which prints 3222 assignments, 2 of them legal.

**Minkowski coordinates.** `example23_minkowski_coordinates.txt` lists 23 points of 3+1 dimensional Minkowski spacetime whose causal relations are those of the causal set of Chapter 7. This is checked by

```bash
python check_minkowski_embedding.py
```

which finds the same 93 relations in both.

## Numerical thresholds

A probe is accepted if the smallest separation between two of its weights, relative to the largest, exceeds $10^{-6}$ and no weight is smaller than $10^{-10}$ in modulus. A self-contraction is accepted as real and positive if its real part is positive and its imaginary part is below $10^{-6}$ of its modulus. A decoded entry is identified with a legal coefficient, or with zero, if it lies within $10^{-3}$ of it, and a pair is treated as constrained by BD legality if the modulus of its entry in the reconstructed $\tilde B$ exceeds 0.2.
